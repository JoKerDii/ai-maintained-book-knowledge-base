# Cheatsheet — Think Faster, Talk Smarter

## The method in one line
**Calm · Unlock · Redefine · Listen · Structure · Focus** — manage your state, lower the bar, reframe, listen, pick a structure, then trim. Aim to be **great, not perfect**.

## Pick a structure (the core decision)
| The moment is… | Use this structure |
|---|---|
| Anything general (answer, update, reaction) | **What? / So What? / Now What?** |
| Stating an opinion / a crisp answer | **PREP** (Point–Reason–Example–Point) |
| Persuading / pitching / proposing | **Problem / Solution / Benefit** |
| Reporting change / a status update | **Past / Present / Future** |
| Toast, tribute, introduction | **WHAT**: Why here → How connected → Anecdote → Thank |
| Answering a question / interview | **ADD**: Answer → Detail an example → Describe the value |
| Giving feedback | **4 I's**: Information → Impact → Invitation → Implications |
| Apologizing | **AAA**: Acknowledge → Appreciate → Amends |
> Rule: choose the structure *first*, then fill it. You assemble in the moment; the structure did the thinking.

## In-the-moment rules
- **Nervous? →** it's a *conversation, not a performance.* Exhale long, greet the anxiety, use your mantra. Channel it — don't fight it.
- **Freezing / over-thinking? →** *dare to be dull.* Get merely-okay words out; fluency beats flawless.
- **Feel "put on the spot"? →** relabel **threat → opportunity** before you speak.
- **Asked a question? →** *pause and listen* (pace & space); **buffer** by paraphrasing to buy time; then answer what was actually asked.
- **Rambling? →** run it through the **Focus filters**: Precision → Relevance → Accessibility → Concision. Cut the rest.
- **Don't know the answer? →** say so honestly + how you'll find out. Credibility > bluffing.

## Focus filters (trim any answer)
**Precision** (exact words) · **Relevance** (only what *this* audience needs) · **Accessibility** (plain, relatable, no jargon) · **Concision** (fewest words). When in doubt, cut.

## Small talk
- Favor **support responses** (ask more, build on theirs) over **shift responses** (redirect to yourself).
- Match self-disclosure levels; don't put your partner on the spot; treat it as a shared game, not a test.

## Apology that works — AAA (Ch 12)
**Acknowledge** the *specific* offense and own it (no "if," no "but") → **Appreciate** the impact, especially the emotional one → **Amends**: state what you'll do or change. Avoid "sorry you felt that way" — it deepens the breach.

## Feedback that lands — the 4 I's (Ch 11)
**Information** (specific, unemotional observation) → **Impact** ("I feel/think…") → **Invitation** (a request, ideally a question) → **Implications** (consequences of changing or not).

## Tells you're in perfectionism/anxiety mode
Scripting every word · replaying the "spotlight" (overestimating how much others notice) · long runway before answering · fillers ("um") from held breath · fixating on being right. → breathe, dare to be dull, pick a structure.

## Prep that pays off (do it cold)
Rehearse **What/So What/Now What**, **PREP**, and **Problem/Solution/Benefit** until automatic; pre-list your **likely Q&A questions**. Structures only help in the moment if you don't have to think about them.
