# Cheatsheet — The New Rules of Marketing and PR

## The single decision rule
**When making any marketing/PR choice → start with the buyer, not the product, because content that solves the buyer's problem is what drives action.** ("You are what you publish.")

## Old Rules vs. New Rules
| Old Rules | New Rules |
|---|---|
| Marketing = advertising to the masses | Reach niche buyers directly with targeted content |
| Interrupt to grab attention | Deliver content at the moment of need |
| PR = get media "ink"; measure clips | Reach buyers directly; measure revenue/goals |
| Release only on "big news," to journalists | Publish continuously, for buyers, keyword-rich |
| One-way spin, "on message" | Authenticity, participation, human voice |
| Agency wins awards | Organization wins business |

## Goal vs. "ball" (the soccer test)
| Ball (wrong focus) | Goal (right focus) |
|---|---|
| Leads, clips, T-shirts | Revenue growth |
| Unique visitors, traffic | Customer retention |
| Google rank for a phrase | Donations / members / votes / applications |
Rule: **traffic and rank matter only if they lead to the real goal.**

## What to do when...
| Situation | Do this | Because |
|---|---|---|
| Starting a program | Run the 4 steps: goals → personas → words/beliefs → content | Everything else builds on personas |
| Overwhelmed | Pick ONE first step (persona research, a few content pages, or read→comment→blog) | The Web is iterative; nobody does it all |
| Writing anything | Lead with the buyer's problem in their words, then prove it | Gobbledygook makes you interchangeable |
| Negative thread erupts | Respond fast, honestly, in the same forum, in your name | Going dark reads as guilt |
| Organic buzz about you | Push it along (link, support, contest) — don't fake or distance | Homemade beats slick; astroturf gets exposed |
| Want a specific reporter | Read them first; send one targeted, plain-text pitch | Broadcast pitching = spam |
| Building a site | Organize by buyer self-selection, not org chart | Buyers don't think in your structure |
| SEM | Many specific long-tail phrases + one landing page each | Generic terms don't convert; homepage can't serve a term |

## Gobbledygook to ban (substitute plain buyer language)
next generation · flexible · robust · world class · scalable · easy to use · cutting edge · mission critical · market leading · industry standard · best of breed · leading · solutions · "we're excited about…" · unparalleled
**Test**: swap in a competitor's name — if it still makes sense, rewrite it.

## Thought leadership: the one rule
**Solve the buyer's problem; never mention your product.** Then choose the form buyers consume:
| Buyer prefers | Use |
|---|---|
| To read, deep | Whitepaper (often gated) |
| To read, light | E-book (free, no registration) |
| Regular updates | E-mail newsletter (problem-solving, not pitch) |
| Live + experts | Webinar |
| The definitive data | Survey/research report |
| Audio (commuters) | Podcast (+ companion blog) |
| Video | Vlog / vodcast / YouTube |

## Free vs. gated content
| Choose FREE (no registration) when | Choose GATED when |
|---|---|
| Goal is reach/awareness | Goal is a contact list / sales leads |
| E-books, viral content | Whitepapers, B2B lead gen |
Trade-off: gating cuts response rates sharply.

## News release checklist
☐ Written for buyers, not just press ☐ Sent even without "big news" ☐ Buyer's exact search phrases embedded ☐ An offer that compels response ☐ Links to landing pages ☐ Social tags (Technorati/DIGG/del.icio.us) ☐ Dual-published: wire + permanent site page

## Landing page checklist
☐ Short copy, simple graphics ☐ Your brand's tone ☐ Written from prospect's POV ☐ Communication, not advertising ☐ Happy-customer quote ☐ Self-contained (few/no links out) ☐ Clear, easy call to action (offer several) ☐ Ask minimum info (email only if possible) ☐ Follow up fast

## Blog on-ramp & ethics
Sequence: **monitor → comment → create.** Niche + passion + authentic independent voice.
Ethics checks: **Transparency · Privacy · Disclosure · Truthfulness · Credit.** Gut test: "What would your mother say?"

## Tells & smells (old-rules thinking to catch)
- "We need a Super Bowl ad / an award / the CEO on TV" → not the new rules
- "Content only works for tech companies" → false (content sells concrete)
- "Bloggers are geeks in pajamas" → the Rathergate mistake
- Site organized by product/geography → confuses buyers
- Media room behind registration / routed through IT → kills the story and speed
- Optimizing on "travel" or one generic keyword → won't convert
- Fake viral / stealth YouTube / sock-puppet profiles → community exposes them

## Governance defaults
Employee blogging → **govern behavior, not the technology** (no harassment/secrets/insider-trading/competitor-bashing across all media). If posts must be reviewed → review **content, not words** (don't gobbledygook it).
