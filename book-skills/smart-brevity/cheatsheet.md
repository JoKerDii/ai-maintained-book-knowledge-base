# Cheat Sheet — Smart Brevity Decisions

## The Core 4 (do these, in order)
| # | Element | Rule |
|---|---------|------|
| 1 | Muscular tease | 6 words or fewer, active, provocative-yet-accurate |
| 2 | Strong first sentence (lede) | ONE sentence; something they don't know |
| 3 | "Why it matters" (Axiom) | Bold it; 1–2 sentences of significance; not redundant |
| 4 | "Go deeper" | Optional link to depth |

## Thresholds & defaults
| Thing | Default |
|-------|---------|
| Subject line / headline | ≤6 words |
| Lede | 1 sentence |
| "Why it matters" | 1–2 sentences |
| Newsletter item | ≤200 words |
| Whole newsletter | <1,000 words (>1,200 = a book) |
| Newsletter items | 5–10, numbered |
| Meeting | 20–25 min (or 5–10 micro) |
| Meeting agenda | 3 bullets, max |
| Slide text | <20 words; 1 message |
| Slide count | ~5–6 (McKinsey: 2 per 20 you want) |
| Speech Big Thought | ≤15 words |
| TED talk | ≤18 min |
| Read speed | ~265 wpm |

## If / then
- **Writing anything** → picture ONE reader; write the ONE thing first; then stop.
- **Don't know your point?** → talk it out loud to someone first, then type that.
- **Point buried?** → apply the Sacca rewrite: first 2–3 sentences say it all.
- **3+ related points/data?** → bullets, not a blob.
- **Want a word/figure seen?** → bold it (beats italics).
- **Long paragraph?** → cap at 2–3 sentences; break it up.
- **Feels curt after cutting?** → breathe voice back (the HUMAN check).
- **Lost necessary nuance?** → bring it back (the ACCURATE check).

## Word tells & smells
| Kill | Use |
|------|-----|
| prevaricate, conundrum, elucidate | lie, jam, explain |
| posit, obfuscate, ubiquitous | assume, hide, everywhere |
| "price point," "core competency" | price, skill |
| could / may / might (fog) | planned / feared / expected |
| passive ("is known to…") | active (Who—doing—what) |
| 3-syllable word | 1-syllable word |

## Weak framing → Strong Axiom
| Weak | Strong |
|------|--------|
| "Here's what's important" | **Why it matters** |
| "A trend we've observed" | **The big picture** |
| "Let's look at the data" | **By the numbers** |
| "In conclusion" | **The bottom line** |

## Axiom menu
Why it matters · The big picture · What's next · Between the lines · The backstory · By the numbers · The bottom line · Reality check · Catch up quick · Zoom in / Zoom out · Go deeper

## Four guiding principles (self-check)
- **Authority** — Be the expert, or find one.
- **Brevity** — Stay short, not shallow.
- **Humanity** — Write like you speak.
- **Clarity** — Style text for impact.

## Tests
- **Tease**: Would you read it if you hadn't written it?
- **Lede**: If this is the only thing they see, is it what you want to stick?
- **Comprehension**: Can a friend spit your point back almost verbatim?
- **Slide**: Would someone at 65 mph get it?

## Anti-patterns
Length to fake depth · burying the lede · repeating the tease · foggy/passive verbs · big blobs of text · chit-chat past meeting start · reading from slides · one more anecdote · emoji overuse · irrelevant identity descriptors.
