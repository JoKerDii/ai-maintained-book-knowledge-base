# Chapter 3: How to Build Better Habits in 4 Simple Steps

## Core Idea
Every habit runs the same four-step loop — cue, craving, response, reward — and the Four Laws of Behavior Change are the practical levers for each step. This is the operating system for the rest of the book.

## Frameworks Introduced
- **The Habit Loop**: Cue → Craving → Response → Reward, forming a neurological feedback loop.
  - **Cue**: triggers the brain to predict a reward (the information).
  - **Craving**: the motivational force; you crave the *change in state* the reward delivers, not the habit itself.
  - **Response**: the actual habit performed (thought or action); depends on ability and friction.
  - **Reward**: satisfies the craving and teaches the brain which cues to remember. Rewards close the loop.
- **The Four Laws of Behavior Change** (to *build* a good habit):
  1. **Make it Obvious** (cue)
  2. **Make it Attractive** (craving)
  3. **Make it Easy** (response)
  4. **Make it Satisfying** (reward)
- **Inversion of the Four Laws** (to *break* a bad habit):
  1. Make it Invisible · 2. Make it Unattractive · 3. Make it Difficult · 4. Make it Unsatisfying.

## Key Concepts
- **Cue → Craving → Response → Reward**: cue triggers craving → craving motivates response → response earns reward → reward satisfies craving and gets associated with the cue.
- **Problem phase** (cue + craving) vs **solution phase** (response + reward).
- **Habit**: a behavior repeated enough to become automatic — solving a recurring problem with as little energy as possible.

## Mental Models
- Ask of any behavior: which of the four steps is breaking down? Then apply the matching law.
- Habits are "reliable solutions to recurring problems" — the brain automates whatever consistently pays off.

## Anti-patterns
- Trying to fix a habit at the wrong step (e.g., adding motivation when the real problem is a missing/unclear cue).

## Worked Example
Thorndike's puzzle-box cats: placed in a box escapable by pressing a lever, cats first explored randomly, stumbled on the lever, escaped to food. Over ~20–30 trials escape time fell from ~1.5 minutes to ~6 seconds. The rewarded action (lever → escape → food) became automatic — the birth of "The Law of Effect": behaviors followed by satisfying consequences get repeated.

## Key Takeaways
1. All habits share one loop; diagnose which step fails before intervening.
2. Use the Four Laws to build, the inversions to break.
3. You don't crave the habit — you crave the state change its reward provides.
4. The reward step teaches the brain which cues are worth noticing next time.
