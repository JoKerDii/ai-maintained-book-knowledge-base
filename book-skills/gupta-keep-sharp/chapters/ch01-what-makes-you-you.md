# Chapter 1: What Makes You You

## Core Idea
The brain's power comes not from isolated anatomical compartments but from the *circuitry and communication between* sections. Memory — the first pillar of a sharp brain — is a dynamic, brain-wide reconstruction, not a static filing cabinet, and every time you use it you change it.

## Frameworks Introduced
- **Memory in three phases: Encoding → Storage → Retrieval**
  - When to use: diagnosing why memory "fails" and where to intervene.
  - **Encoding**: perception via senses → hippocampus integrates into one experience. *You must pay attention to encode.* Attention is the single most important factor in what you remember.
  - **Storage**: sensory (fraction of a second) → short-term (~7 items, hippocampus-linked) → long-term (cortex-linked, effectively unlimited, indefinite). Alcohol and sleep deprivation block the short→long transfer.
  - **Retrieval**: pulling info from unconscious into conscious mind. "Bad memory" for names is usually an attention or retrieval problem, not systemic failure — and is trainable.

## Key Concepts
- **Neuroplasticity**: the brain's ability to form and reorganize synaptic connections throughout life (first noted by William James, 1890; now measurable via fMRI).
- **Plasticity is a two-way street**: it's almost as easy to drive changes that impair as to improve. "Older people are masters at encouraging plastic brain change in the wrong direction" (Merzenich).
- **Synapse / dendrite / neurotransmitter**: connection point, receiving branch, chemical messenger (dopamine, norepinephrine, epinephrine).
- **"What fires together wires together"**: repeated signals strengthen synapses — the biology of "practice makes perfect."
- **The value of forgetting**: dedicated "forgetting neurons" (discovered 2019), most active during sleep, keep the brain functional. "In order to remember, we have to forget to some degree."

## Mental Models
- Memory as **a jigsaw puzzle actively reassembled** from scattered pieces (name, appearance, sound, feeling — each from a different brain region), not a photo retrieved whole.
- The brain is **not a computer** — it has no fixed memory capacity; perception is active interpretation of what you attend to and anticipate, not passive input.
- Attention is the gate: "You have to pay attention to properly encode a memory." Read that twice.

## Anti-patterns
- **Treating memory as memorizing / a warehouse**: the wrong metaphor; memory is a learning process that constantly rewrites itself.
- **Relying on memory hacks alone**: tricks strengthen components, but true improvement requires working on *all* brain functions.
- **Assuming you have a globally "good" or "bad" memory**: you're adept at some types and weak at others; weaknesses are targetable.

## Key Takeaways
1. Attention is the linchpin of memory — divided attention (multitasking) sabotages encoding.
2. Memory is reconstructive and malleable — even healthy memories can be implanted or altered (Loftus's Bugs-Bunny-at-Disney studies).
3. To preserve memory at the cognitive level, work on the whole brain, not isolated drills.
4. The brain is alive, growing, and rewiring throughout life — dynamism offers hope.
5. Every experience slightly rewires the brain; repeated behavior entrenches dendrites, novelty grows new ones.
