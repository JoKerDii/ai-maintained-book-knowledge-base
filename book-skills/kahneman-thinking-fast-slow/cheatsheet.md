# Cheatsheet — Thinking, Fast and Slow

Decision rules and tells you'd want beside you while judging, forecasting, or choosing.

## Bias → Tell → Countermove

| If you notice… | You're probably in… | Do this |
|---|---|---|
| A story feels complete and obvious | WYSIATI / illusion of validity | Ask "what's missing?"; check evidence quality, not just coherence |
| A vivid case drives your risk estimate | Availability heuristic | Look up the actual base rate / frequency |
| A number was mentioned before you estimated | Anchoring | Estimate independently first; argue the anchor is wrong |
| A description matches a stereotype | Representativeness / base-rate neglect | Start from the base rate, adjust by evidence's real validity |
| Extreme result → confident causal story | Regression fallacy | Expect regression to the mean; no cause needed |
| "This time/we are different" | Planning fallacy / competition neglect | Take the outside view (reference class) |
| Confident expert in a noisy field | Illusion of skill | Apply the two-condition test (below) |
| One good trait colors the whole judgment | Halo effect | Score independent traits separately |
| You're holding a loser to avoid selling at a loss | Sunk cost / disposition effect | Ask "would I buy this today?" |
| Choice flips when reworded | Framing effect | Restate in the opposite frame + common units |

## Should I trust this intuition? (Expert-intuition test)
1. Is the environment **regular/predictable** (valid cues exist)?  → if No, **don't trust it**.
2. Was there **prolonged practice with rapid, clear feedback**? → if No, **don't trust it**.
3. Both Yes → trust the intuition. (High validity: anesthesiology, chess, firefighting. Low: stock picking, long-term political forecasting.)
> Subjective confidence ≠ accuracy. Certainty is a feeling, not evidence.

## Prospect theory in one screen
- Value is over **changes from a reference point**, not final wealth.
- **Loss aversion**: losses hurt ~**1.5–2.5×** more than equal gains delight.
- **Diminishing sensitivity**: $0→$100 feels bigger than $900→$1000.
- **Decision weights ≠ probabilities**: rare events overweighted; near-certain events underweighted.

## Fourfold pattern (risk attitudes)
| | Gains | Losses |
|---|---|---|
| **High probability** (certainty effect) | Risk-**averse** — take the sure thing (accept unfavorable settlement) | Risk-**seeking** — gamble to avoid sure loss (reject favorable settlement, "go to court") |
| **Low probability** (possibility effect) | Risk-**seeking** — buy lottery tickets | Risk-**averse** — buy insurance |

## Forecasting rules of thumb
- **Regress predictions to the mean** by (1 − correlation): weak evidence → stay near baseline.
- **Equal-weight formulas beat holistic judgment** in low-validity settings; consistency > cleverness.
- **Reference-class base rate first**, case details second.
- Run a **premortem** before locking a big decision.

## Two selves — decision defaults
- **Experiencing self** feels moments; **remembering self** keeps score via **peak-end + duration neglect**.
- Memory over-rewards good endings and ignores duration → don't confuse a good story with a good life.
- **Focusing illusion**: "Nothing in life is as important as you think it is while you are thinking about it." Discount how much any single change (income, climate, new car) will shift lasting well-being.

## System 1 vs System 2 (fast reference)
| | System 1 | System 2 |
|---|---|---|
| Speed | Fast, automatic | Slow, effortful |
| Feel | Effortless, always on | Costly, lazy, depletable |
| Job | Impressions, intuitions, patterns | Checking, computing, self-control |
| Failure mode | Biases, WYSIATI | Endorses System 1 without checking |
> System 2 is the lazy controller: it usually ratifies System 1. Deliberate friction (slow down, ask for base rates, reframe) is the only reliable fix.
