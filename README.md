# AI Maintained Book Knowledge Base

This repository contains a curated collection of book skill folders used for learning and reference.

## What this repo is

1. A repository of skills for books you can use as a study and exploration toolkit.
2. A small website for browsing book-related topics and reading the associated markdown content.

## How to use it

- Open the generated site in your browser to explore the available book skills.
- Use the tabs to switch between skill folders.
- Choose a markdown file from the dropdown to preview its content.

## Purpose

The goal is to make book knowledge easier to browse, preview, and learn from in a simple, lightweight website experience.
