# AI Maintained Book Knowledge Base

This repository contains a curated collection of book skill folders used for learning and reference.

## What this repo is

1. A repository of skills for books you can use as a study and exploration toolkit.
2. A small website for browsing book-related topics and reading the associated markdown content.

## How to use it

- Run `./refresh_site.sh` to regenerate `index.html`, `styles.css`, and `app.js` from the markdown on disk.
- Open `index.html` in your browser to explore the content.
- Switch between the two top-level tabs:
  - **Summary and Insights** — the `cheatsheet.md`, `glossary.md`, and `patterns.md` files from each folder in `book-skills/`.
  - **Guided Reading** — the quiz and arguments-and-evidence files from `reading-helper/`.
- Inside a tab, use the book buttons to switch books and the dropdown to choose a markdown file.

## Purpose

The goal is to make book knowledge easier to browse, preview, and learn from in a simple, lightweight website experience.
